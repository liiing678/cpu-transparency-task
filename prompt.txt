想做一个在浏览器里检查装配体的三维查看器，主要用来看透明外壳里的零件，也能直接点击画面选中对象。目前只有 scenes 目录里的合成场景，以及格式说明和检查数据，查看器和渲染代码都还没有。

用 JavaScript ES2022 或 TypeScript 开发，通过本地 HTTP 服务在浏览器打开。渲染在 CPU 上完成，三维变换、裁剪、三角形光栅化、深度判断、纹理插值、透明混色和点选都需要自己实现，不使用 WebGL、WebGPU、现成三维引擎或光栅化库。Canvas 2D 用来显示算好的像素和绘制界面，界面、构建和图像编码可以用通用库。

场景格式和渲染规则按 scene_format.txt 来。提供的场景都能加载，也要能导入同格式的 JSON 文件；每份场景是独立的，不用另找素材。画面尺寸取场景中的设置，对象的缩放、旋转和平移要生效，三角形两面都可见。三角形越过视锥边界时，只裁掉外面的部分；相机后方的几何不能出现在画面里。相邻三角形之间不能漏出缝隙，共享边也不能多算一次混色。斜面上的纹理要做透视正确的插值。

透明面相交的情况是这次的重点。同一张面在画面左边可能更靠前，到右边又退到另一张面后面，需要按每个像素的实际深度混色。把输入中的对象顺序调换后，颜色、深度和点选结果都应一样。不透明面要挡住后面的内容，完全透明的面则不影响颜色、深度和点选。

鼠标拖动时围绕场景目标点转动视角，滚轮拉近拉远。页面上可以切换场景、恢复初始相机，并把当前画面导出为 PNG。旋转和缩放范围可以按这些场景安排。点击后显示对象的 id、名称和该像素的相机距离，点到背景就显示未选中。半透明外壳也能被选中，按最近的非零透明度表面判断。浏览器或画布经过缩放后，鼠标位置仍要对应正确的输出像素；刚转完视角就点击，也要用当前画面的结果。导入非法场景时说明具体原因，并清掉旧画面。

渲染入口放在 src/renderer.mjs，按 scene_format.txt 导出 render，返回 RGBA、相机距离和对象 id 数组。浏览器页面和 Node.js 检查都调用这套实现，入口不要依赖 DOM。宽高分别支持 64 到 512 的任意整数，场景最多 800 个三角形、256 个对象，纹理每边最多 64。没有固定帧率要求，拖动时可以降低分辨率，松开后恢复到指定尺寸。同格式的新场景也要能用，不能按现有场景的名称、id 或采样位置写死输出。

源码和网页放在项目里，保留附带的原始材料。说明里写清依赖怎么安装、网页怎么启动、从项目根目录怎么运行检查，拿到一份干净的项目后照着操作就能使用。检查方法和容差按 acceptance.txt，checks/probes.json 中有部分像素的手算结果。
